# 01. Getting Started

Index adds **persistent manual hierarchy ordering** to the normal Unreal Engine World Outliner. You can reorganize a level without artificial name prefixes and without replacing Unreal's attachment or Folder hierarchy.

## How the editing experience works

Drag a loaded Actor or Folder onto the top or bottom edge of a compatible row to insert it before or after that row. A full-width colored insertion line previews the destination. Hold **Alt** by default to enlarge the before/after zones. Save your level to retain the new arrangement.

## First-use checklist

Confirm the Index Editor plugin is enabled, open the standard World Outliner, try a drag on a disposable level, look for the insertion line, release and save. If the center of a row changes parenting instead, use its edge or the Force Reorder modifier.
